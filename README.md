# StrongLifts 5x5

A mobile-first, local-only StrongLifts 5x5 workout tracker.

Open `index.html` directly in a browser, or run a simple local server:

```sh
python3 -m http.server 8000
```

Workout history and weekly starting weights are stored in the browser's local storage. Set starting weights from the Progress view; they remain available even after workout history is deleted. Use the `CSV` button in the top right to export it.
